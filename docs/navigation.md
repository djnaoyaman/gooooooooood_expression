# 画面遷移の回帰検証

詳細は `#explore/表現ID` などのURLと連動する。最初に開いた詳細を履歴へ追加し、関連表現への移動は同じ詳細履歴を置き換える。閉じる／Escapeで元の一覧へ戻る。直接開いた詳細URLは閉じても外部ページへ戻らず、同じ画面の一覧を表示する。

ブラウザの戻る・進むでpopstateとhashchangeが両方発生しても同じURLを二重描画しない。詳細を差し替えた後に届く古いcloseイベントは、新しいダイアログや履歴を操作しない。詳細を閉じると元のボタンへフォーカスを戻す。

コレクションは以前の検索語や領域等の条件を解除して表示する。「表現を探す」でコレクションを抜けられる。存在しない表現IDは一覧URLへ戻す。索引のA–Z順はカードの名前順へ引き継ぐ。

ビルド後、開発用Playwrightをインストールした環境で `node scripts/verify-navigation-browser.mjs` を実行する。PLAYWRIGHT_MODULE と CHROMIUM_EXECUTABLE で既存のテスト用ランタイムも指定できる。外部GAスクリプトを止め、デスクトップ・モバイルの戻る／進む、Escape、直接リンク、関連詳細、コレクション、無効URL、スキップリンク、全表現の表示を検証する。
